# AI Visibility

AI Visibility is a mobile-first GEO/AEO subscription platform prototype for monitoring how brands appear in AI answer engines.

## V1 goals
- Executive dashboard
- Client and subscription overview
- Visibility scan queue
- Competitor comparison
- Agent activity and approval queue
- Daily executive report

This first version uses demo data. Live provider integrations, billing and outbound communication will only be enabled after explicit configuration and testing.
