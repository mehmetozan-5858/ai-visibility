# AI Visibility — Professional Website Foundation v1

## Positioning
TR: Yapay zekâ aramalarında markanız ne kadar görünür? Görünürlüğünüzü ölçün, eksikleri keşfedin, iyileşmeyi takip edin.
EN: Can AI search find your brand? Measure visibility, uncover gaps, and track improvements.

## Public navigation
Product / Ürün; How it works / Nasıl çalışır; Industries / Sektörler; Sample report / Örnek rapor; Pricing / Fiyatlandırma; Sign in / Giriş.
Primary CTA: Free preliminary analysis / Ücretsiz ön analiz.

## Homepage sections
1. Hero: one measurable promise, two CTAs, actual product screenshot when verified.
2. Problem: unanswered brand and competitor questions; no fabricated metrics.
3. Three steps: Analyze → Improve → Monitor.
4. Features: AI visibility scan, source-linked evidence, competitor comparisons, actionable recommendations, monthly tracking. Mark planned features as planned until live.
5. Industries: manufacturing/export, specialist B2B services, e-commerce, agencies.
6. Sample report: conspicuously labeled demo until real evidence exists.
7. Pricing: no invented prices; packages published only after payment, legal and delivery checks.
8. Trust: methodology, data freshness, privacy, limitations, contact, FAQ.
9. Footer: privacy, terms, support, company details when verified.

## Visual system
Premium dark navy #0B1220; emerald accent #27C99A; off-white #F5F7FA; readable contrast. Large typography but compact mobile layout; no autoplay videos; no borrowed competitor visuals. Responsive from 320px. Consistent cards, generous spacing, accessible keyboard navigation, visible focus, reduced motion support.

## Conversion
Landing → free limited scan → evidence-based summary → paid audit → remediation proposal → recurring monitoring. Public pages separate from authenticated customer and admin screens. Do not promise rankings, leads, revenue or guaranteed results.

## Launch gates
1. Locate and inventory current frontend routes before code replacement.
2. Implement UI on a separate branch with real content and clear demo labels.
3. Test mobile, keyboard, TR/EN, performance, analytics consent, login boundaries.
4. Verify actual payment and report fulfillment before publishing paid CTA.
5. Merge only after passing build, tests and live preview.

## Status
Design and content specification only. No live deployment or functionality claimed.
